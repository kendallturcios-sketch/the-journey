For pastors adapting this

These are single HTML files. Nothing to install — open one and it works. Add it to a phone's home screen and it behaves like an app.

To make it yours: click Fork at the top of the GitHub repo. That makes your own copy under your account; nothing you change there affects ARISE Miami's app. Church name, ministries, schedule and every lesson are plain text near the top of each file.

Your copy doesn't send anything to ARISE's Planning Center. Sending only works from ARISE Miami's own site. To record answers in your own Planning Center, you'll need your own copy of the server in supabase/functions.

Codes: the facilitator app shows a new session code and make-up code for each level every day. To try every level on any day, add ?preview to the app's address.

Please keep the About page and the credit line in the app.

Scripture is Berean Standard Bible in English and Reina-Valera 1909 in Spanish — both public domain, so there is nothing to license and it works with no internet.
